# 亲戚称呼计算器（微信小程序）

完全离线运行的微信小程序，用于根据亲戚关系链（点选或打字）快速计算出彼此的准确称呼，并展示称呼背后的长幼典故、双重视角关系路径与日常称谓说明。

---

## 功能特性

- **点选与自然语言解析**：支持点选关系键（长辈 / 平辈 / 晚辈 / 配偶），也可以直接输入自然语言（例如「爸爸的哥哥的妻子」）。
- **正反双向称呼**：不仅算出「你该叫他什么」，还根据当前用户的性别准确给出「他该叫你什么」。
- **长幼消歧与病态链拦截**：
  - 遇到需要区分长幼才能确定的称谓（如堂兄 / 堂弟、姑妈 / 姑姐），提供二选一选项，绝不静默猜错。
  - 遇到现实不存在的关系（如男性的老公、女性的老婆），前置置灰禁用并给出清晰拦截提示。
- **称谓典故与文化渊源**：针对常见称谓（如「伯、仲、叔、季」、「姑」、「舅」、「堂 / 表」等）提供弹窗典故解析。
- **视角的双向路径图**：直观展示「你的视角」与「他的视角」的关系图解，长链自动折叠为纵向排版。
- **纯本地、零依赖运行**：核心算法和页面完全脱离外部网络，不收集任何用户隐私数据，计算秒级响应。

## 开发与运行

### 1. 本地测试

本项目所有算法和页面业务逻辑均编写了 Node.js 单测，**无需依赖任何第三方 npm 包**即可直接运行：

```bash
# 运行全部称呼计算用例（632+ 项）
npm test

# 运行页面状态与操作流冒烟测试（70+ 项）
node tests/ui-smoke.js

# 运行称呼审计与覆盖度检查
node tests/audit.js
```

### 2. 小程序运行与调试

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具，选择 **导入项目**。
3. 选择当前项目根目录 `kinshipCalculator`。
4. AppID 可以填入自己的小程序测试号或正式 AppID。
5. 导入后即可在模拟器中实时查看与调试。

## 隐私说明（小程序提审注意）

- 本项目所有计算完全在前端本地完成，不向任何服务器发送网络请求，不收集用户信息。
- 小程序内提供了两处**复制到剪贴板**能力：
  1. 结果页中的「复制」称呼结果；
  2. 关于页中的「复制反馈模板」。
- 若在微信小程序管理后台将用户隐私保护指引设置为「未采集用户隐私」，提审时微信会提示检测到 `Clipboard` 隐私接口：
  - **建议处理方案**：在后台「用户隐私保护指引」中勾选并声明使用剪贴板权限，说明用途为「用于用户主动复制称呼结果及反馈模板」即可正常通过审核；
  - **替代方案**：如确实不需要复制能力，可移除这两处 `wx.setClipboardData` 调用。
